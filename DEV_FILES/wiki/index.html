What this application is, in one paragraph

pixaproof.com is the marketing site for PixaProof, Innov8tif's image-authenticity verification product. It has three pages: a long single-page landing (/) with anchor navigation, a contact page that sends visitors to the sales team's email (/contact), and the privacy policy (/privacy). There are no forms and no logins for visitors. Its job is to rank, to load fast and safely, and to send people to "Request Demo".

The stack: Laravel 13 Laravel with Statamic 6 Core installed inside it Statamic. Statamic owns the pages, navigation, assets and the control panel. Packages Addon add the Eloquent driver (content in SQLite) and the Marketing Toolkit (every SEO tag, the sitemap, robots.txt, llms.txt, favicons, GA4 and the redirects). Our code Custom is the Blade templates and components, the security headers and CSP reporting, the content import command and the deployment. Page 0b sorts every file into those four buckets.

The five ideas that explain most of the code

IdeaWhere you'll see it
1. Statamic default first, then the toolkit, then Laravel, then custom. The site was converted from plain Laravel in October 2026 with that rule. When you are about to write something, check whether Statamic or the toolkit already does it.Page 0b
2. Copy lives in templates, settings live in the CP. The homepage and contact copy are Blade; titles, descriptions, navigation, redirects, the privacy text and the GA4 ID are content an editor can change at /cp.Page 2, Page 3
3. Nothing SEO-related is hand-written. One tag, <s:seo:head />, prints every meta tag, JSON-LD block, icon link and tracking script.Page 3
4. One SQLite file holds everything. Content, users, redirects, the 404 log, the cache and the queue. Deploys back it up before migrating.Page 4, Page 8
5. A snapshot test guards every public URL. Titles, descriptions, canonicals, JSON-LD and the 22 legacy redirects are recorded; any change has to be intended.Page 9

Statamic in one minute: a collection is a content type (here pages); an entry is one item in it; a blueprint (YAML) lists an entry's fields; a template is the view an entry renders with; a navigation is an editable menu; a global set is site-wide settings; tags like <s:nav:main> are Statamic's view helpers, usable in Blade.

  1. bootstrap/app.php: routing and the one middleware we add.

  4. config/seo.php: the toolkit's options and our two changes.
  5. DEV_FILES/statamic-conversion/00-plan.md: why it is built this way.
