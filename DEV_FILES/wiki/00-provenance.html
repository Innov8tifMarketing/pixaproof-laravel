0b. Stock vs custom: who wrote what

Much of what runs here is framework behaviour that is only configured in this repo. This page sorts every moving part into four buckets, so you know whose documentation to read and where a bug can possibly live.

BadgeMeaningWhere the code isRead
LaravelLaravel framework or skeleton behaviour. We may have set a config value.vendor/laravel/frameworklaravel.com/docs
StatamicA Statamic core feature used as shipped. Blueprint YAML and config/statamic/* count as Statamic configuration.vendor/statamic/cms; our YAML in resources/blueprints/statamic.dev
AddonA package we installed: the Eloquent driver, the Marketing Toolkit, Boost, blade-heroicons, Alpine, Motion, Tailwind.vendor/<package>, node_modules/The package's docs (the toolkit's are in vendor/jotham-lec/statamic-marketing-toolkit/docs/)
CustomWritten in this repo.app/, resources/views/, resources/js, routes/, deploy.phpThe code and this wiki

Custom code layered on a default gets two badges, for example Custom on Statamic: a class of ours that extends or hooks into a framework feature. There you need both sets of docs.

How to tell, without this page

  • Namespace. App\… is ours. Illuminate\… is Laravel. Statamic\… is Statamic, including the Eloquent driver's Statamic\Eloquent\…. JothamLec\MarketingToolkit\… is the toolkit.
  • Routes. php artisan route:list --except-vendor lists ours (just POST csp-report); --only-vendor lists everyone else's.
  • Config. config/statamic/* and config/seo.php are a package's options with our values.

Where the line moved

Until October 2026 this was a plain Laravel site. The conversion replaced custom code with defaults, in this order of preference: Statamic, the toolkit, Laravel, custom.

Was customNow
Route::view pages, layouts/base + layouts/appEntries in a structured pages collection, Blade templates with Statamic's names
Hand-written title, description, canonical, Open Graph and Twitter tagsThe toolkit, from each entry's SEO tab and SEO & brand
Hard-coded GA4 snippet (every environment), GTM partialsToolkit tracking (production only)
