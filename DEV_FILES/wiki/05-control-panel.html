5. Control panel

/cp is Statamic's control panel Statamic, with the Marketing Toolkit's screens Addon: Toolkit added. It is where everything that isn't page copy gets edited.

What an editor can change

ScreenChangesOrigin
Collections → PagesEach page's title, slug, template, SEO tab (title, description, share image, noindex, canonical…), and the privacy policy's text (markdown)Statamic
Navigation → Main / FooterThe header and footer linksStatamic
AssetsImages in public/media (share image, icon)Statamic
Globals → SEO & brandDefault description and share image, icon, publisher, GA4 ID, robots.txt lines, verification codesAddon: Toolkit
Tools → SEORedirects (with hits and CSV import/export), the 404 log, site reportsAddon: Toolkit
DashboardThe SEO widget (config/statamic/cp.php)Addon: Toolkit

The homepage and contact copy are not editable here: they live in resources/views/home.blade.php and resources/views/contact.blade.php.

Editions and users

  • Statamic Core (free): one control panel user, no roles, no revisions. config/statamic/editions.php keeps 'pro' => false.
  • Marketing Toolkit Pro: set in the same file. Local and staging need no licence; the live site does.
  • Users are Statamic database users Statamic on Laravel's users table and App\Models\User. Create one with php please make:user (make it a super user). Each environment has its own.

Why the control panel has no report-only CSP. Statamic's control panel is a Vue application that doesn't follow the site's policy. Reporting its violations would bury the site's own. app/Http/Middleware/SecurityHeaders.php skips that one header when Statamic::isCpRoute() is true; the enforced headers still apply.
