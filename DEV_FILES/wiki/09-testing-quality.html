9. Tests & quality gates

About 70 PHPUnit tests in roughly 25 seconds. One test guards the whole public URL surface; the rest pin down specific promises (security headers, the import, the homepage's structure).

How tests get their content

tests/TestCase.php Custom on Laravel uses RefreshDatabase with $seed = true. Laravel 13 migrates the in-memory SQLite database once per run, seeds it with database/seeders/DatabaseSeeder.php (which runs pixaproof:import-content), and wraps each test in a transaction that is rolled back. Before the database is refreshed the media disk is faked, so the import's image copies never touch public/media; the csp log channel is null, so test reports never reach storage/logs.

tests/Feature/ImportStatamicContentTest.php needs an empty site, so its setUp() deletes the seeded content inside the test's transaction.

The URL snapshot

tests/Feature/Guard/UrlSnapshotTest.php requests every public URL (the 3 pages, a 404, all 22 legacy redirects, sitemap.xml, robots.txt, llms.txt, POST /csp-report) and records the status, the Location, and the head metadata: title, description, canonical, robots, every og:/twitter: tag and the decoded JSON-LD. It compares the result with tests/__snapshots__/urls.json.

  • Per-machine and per-request values are normalised: the app URL ({app_url}), CSP nonces, ?v= hashes, Glide s= signatures (derived from APP_KEY) and sitemap dates. The order of llms.txt's list lines is sorted, because the toolkit orders pages saved in the same second arbitrarily.
  • Indexing is switched on for the test (noindex_outside_production off), so the snapshot shows production's robots meta.
  • For an intended change: UPDATE_SNAPSHOTS=1 php artisan test --filter=UrlSnapshotTest, then review the diff in git like code.
