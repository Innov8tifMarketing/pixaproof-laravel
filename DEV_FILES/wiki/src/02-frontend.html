2. Templates & frontend

Each page is an entry rendered by a Blade template. The template extends one layout, which pulls in the toolkit's head tags, the navigation and the built assets.

Blade templates don't get Statamic's layout automatically. Statamic wraps an Antlers template in layout for you; a Blade template is rendered as-is, so each one says @extends('layout'), exactly as in plain Laravel. The entry's fields are available as variables ($title, $content) and the entry itself as $page.

Navigation

The navbar (desktop and mobile) and the footer's "Navigation" column loop over Statamic navigations {{S}} with the Blade tag syntax:

<s:nav:main>
    <a href="{{ $url }}">{{ $title }}</a>
</s:nav:main>

The "Request Demo" button and the footer's contact and legal links stay in Blade. Links to the entries are plain paths (/contact, /privacy); Statamic entries have no Laravel route names.

Components

Anonymous Blade components {{C}} in [[resources/views/components]]: section (the reveal-on-scroll shell and centred header), button, icon-card, check-list, stat, rotating-text, navbar, footer and four graphics/*. Icons are blade-heroicons {{A}}.

JavaScript and CSS

  • [[resources/js/app.js]] {{C}} imports Alpine {{A}} with the collapse plugin (mobile menu, accordions) and intersect (reveal on scroll), defines window.Motion (animation helpers used inside Alpine expressions) and starts Alpine last so those helpers exist first.
  • [[resources/css/app.css]] {{C}}: Tailwind 4 {{A}} with @theme brand colours (primary sky, neutral slate, accent amber), the forms and typography plugins, and the [x-cloak] rule.
  • [[vite.config.js]] with [[vite-plugin-sri.js]] {{C}}: integrity hashes are written into the Vite manifest so @vite prints integrity="…", and Laravel adds the CSP nonce to the tags.

Why Alpine from npm and not Livewire? The site had no Livewire components; Livewire was loaded only because it bundles Alpine. Loading Alpine directly removes a whole framework (and its session-expiry 419 handler) for the same behaviour. Livewire also bundled persist and focus; nothing used them, so only collapse and intersect were added.
